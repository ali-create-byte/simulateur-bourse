# Simulateur d'investissement — Bourse de Casablanca

Simulateur en français pour estimer l'évolution d'un portefeuille d'actions à la Bourse de Casablanca (montants en MAD) : frais de courtage, droits de garde, fiscalité marocaine (retenue sur dividendes, impôt sur les plus-values avec seuil d'exonération), 3 scénarios et comparaison avec un livret d'épargne.

**Utiliser en ligne :** https://ali-create-byte.github.io/simulateur-bourse/

Un seul fichier `index.html`, sans dépendance externe : il suffit de l'ouvrir dans un navigateur.

> Simulation indicative. Les performances passées ne garantissent pas les résultats futurs. Ceci n'est pas un conseil en investissement.
